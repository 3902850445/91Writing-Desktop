# 暗线追踪（Dark Thread Tracking）

## 概念

暗线追踪是 WS 方法论的"数值状态层"——用 YAML 配置 + Markdown 快照，跨章节追踪角色的隐藏状态、势力关系、伏笔进度。

解决的核心问题：**写到第 30 章时，第 5 章埋的伏笔你还记得吗？**

## 配置结构

`dark-threads/config.yaml`：

```yaml
variables:
  merit: 0              # 功德值
  tribulation: 0        # 难印数
  realm: "太乙金仙"     # 境界
  headband_trigger: 0   # 紧箍咒触发次数

dark_threads:
  niu_mowang_attitude:
    description: "牛魔王对孙悟空的态度变化"
    stages:
      - "敌对：五百年的积怨"
      - "戒备：发现符文后的警惕"
      - "松动：确认同类后的动摇"
      - "同盟：共同面对倒计时"
    current_stage: 0

  flame_mountain_seal:
    description: "岩浆河底古老封印的揭秘进度"
    stages:
      - "隐藏：芭蕉扇屏蔽符文"
      - "浮现：扇柄裂痕导致屏蔽失效"
      - "识别：金箍固件与符文代码同源"
      - "激活：倒计时启动"
    current_stage: 0
```

## 命令

### 更新暗线状态

```bash
ws darkthread 3 --set merit=10 --set niu_mowang_attitude=1 \
  --event "牛魔王态度开始转变，达成暂时同盟"
```

这会：
1. 读取上一章的暗线状态
2. 应用变化（`merit` 设为 10，`niu_mowang_attitude` 推进到阶段 1）
3. 生成新的快照 `dark-threads/ch003_snapshot.md`

### 查看当前状态

```bash
ws darkthread 3 --show
```

## 快照格式

`dark-threads/ch{NNN}_snapshot.md`：

```markdown
# 暗线快照: 第 N 章后

## 数值状态

| 变量 | 当前值 | 上一章值 |
|------|--------|----------|
| merit | 10 | 0 |
| tribulation | 1 | 1 |

## 暗线进度

| 暗线 | 当前阶段 | 上一章阶段 |
|------|----------|------------|
| niu_mowang_attitude | 1/4 ← 推进 | 0/4 |
| flame_mountain_seal | 0/4 | 0/4 |

## 本章关键事件
牛魔王态度开始转变

## 变化明细
- **niu_mowang_attitude**: 阶段推进 +1

## 暗线连续性提醒
- 下一章必须至少推进一条暗线
- 数值变化必须与剧情一致
- 角色状态变化需符合 SKILL.md 设定
```

## 暗线在写作中的注入

`write.py` 会自动将最新快照注入到写作指令中：

```markdown
## 暗线状态（必须在此章推进）
# 暗线快照: 第 N-1 章后
...
```

Agent 必须在正文中推进至少一条暗线。

## 暗线在自检中的检查

`anchor.py` 会检查：
- 暗线关键词或描述是否出现在正文中
- 如果没有提及任何活跃暗线，标记 "暗线无遗忘" 为失败

## 暗线设计原则

1. **数量控制**：短篇 1-2 条，中篇 2-4 条，长篇 3-6 条
2. **类型搭配**：
   - 角色关系暗线（如"牛魔王态度"）
   - 世界观揭秘暗线（如"火焰山封印"）
   - 主角成长暗线（如"金箍真相"）
3. **节奏控制**：不必每章都推进所有暗线，但要确保每条暗线定期出现
4. **章末呼应**：暗线推进最好与章末钩子结合

## 类型模板

`scaffold.py` 内置了按 genre 自动生成的暗线模板：

| 类型 | 数值变量示例 | 暗线示例 |
|------|-------------|---------|
| 玄幻/仙侠/武侠 | 境界、气运值、功法进度、仇敌值 | 宿命觉醒、宗门态度、神器封印 |
| 科幻 | 科技等级、势力声望、资源点、文明指数 | AI 叛变、外星文明接触、技术奇点 |
| 都市 | 财富值、人脉网、势力影响力、健康状况 | 幕后黑手身份、商业联盟、情感羁绊 |
| 悬疑/推理 | 线索碎片数、嫌疑人信任度、真相进度 | 真凶动机、证人保护、警局内鬼 |
| 言情 | 情感进度、误会指数、外部压力值 | 家族恩怨、身份秘密、第三者介入 |

## 注意事项

- 暗线配置在 `ws init` 时自动生成，后续可手动编辑
- 暗线数值变化必须通过 `ws darkthread` 命令更新，不要直接修改 snapshot 文件
- 如果某章没有推进暗线，`anchor.py` 的初筛会标记警告
