# 章节撰写（Chapter Writing）

## 概念

章节撰写不是让 AI "自由发挥"，而是**在严格约束下的精密写作**。写作指令（prompt）组装了所有前置素材：作者风格基线、场景推演报告、世界观约束、暗线状态。Agent 必须在这些约束内创作。

## 核心约束

1. **缺素材不撰写**：如果作者 SKILL、场景推演、世界观、暗线状态任一缺失，拒绝撰写
2. **风格严格一致**：符合作者 SKILL.md 的「表达 DNA」和「叙事结构癖好」
3. **角色不 OOC**：对话和行动必须符合角色 SKILL.md 的「台词指纹」和「行动模式」
4. **世界观数值一致**：功德/境界/物品数量等不得前后矛盾
5. **暗线必须推进**：不能遗忘，必须在此章有进展
6. **情节与推演一致**：不得擅自更改推演报告中的角色决策
7. **章末留强钩子**：悬念/危机/反转，让读者必须点下一章

## 工作流程

```bash
ws write 1 --scene 场景名 --style 作者名
```

### 检查前置素材

`write.py` 会检查：
- 作者 SKILL.md 存在
- 场景推演报告存在
- 世界观设定存在
- 暗线状态存在
- 章节大纲存在

任一缺失则返回 `missing_prerequisites`，拒绝撰写。

### 组装写作指令

生成 `chapters/ch{NNN}_prompt.md`，包含：

1. **章节信息**：章号、标题、内容简述、预计字数、关联场景
2. **作者风格基线**：作者 SKILL.md 前 3000 字
3. **世界观约束**：worldviews/*.md 前 2000 字
4. **暗线状态**：最新暗线快照
5. **场景推演报告**：report.md 前 2000 字
6. **写作要求**：结构、风格、一致性、版权安全
7. **输出格式**：纯正文、Markdown、中文引号、字数范围
8. **自检清单**：写完后对照检查

### 启动写作 Agent

Agent 的 system prompt 包含作者 SKILL.md 的风格基线，user prompt 是完整的写作指令。Agent 输出纯正文，保存到 `chapters/ch{NNN}.md`。

## 章节文件结构

```markdown
# 第 N 章

（正文，约 2000-4000 字）
```

**不要**在正文中包含：
- 写作思路说明
- 角色分析
- 与 AI 的对话
- 英文引号（必须用「」）

## 暗线注入

`write.py` 会自动将最新暗线快照注入写作指令：

```markdown
## 暗线状态（必须在此章推进）
# 暗线快照: 第 N 章后

## 数值状态
| 变量 | 当前值 | 上一章值 |

## 暗线进度
| 暗线 | 当前阶段 | 上一章阶段 |
```

Agent 必须在正文中推进至少一条暗线。

## 字数控制

| 篇幅 | 每章字数 | 说明 |
|------|---------|------|
| 短篇 | 2000-3000 | 节奏紧凑 |
| 中篇 | 3000-5000 | 信息密度适中 |
| 长篇 | 4000-6000 | 充分展开 |

## 注意事项

- 如果章节已存在，`ws write` 只生成 prompt，不会覆盖正文
- 写作 Agent 可能一次写不完，可以分多次调用
- 写完后必须运行 `ws check` 进行锚定自检
- 如果自检未通过，根据修复建议修改后再保存
