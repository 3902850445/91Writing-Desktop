# 灵魂蒸馏（Soul Distillation）

## 概念

灵魂蒸馏是从真实人物或虚构角色的资料中提取"思维操作系统"——不是传记，而是**角色扮演指南**。产出的 SKILL.md 包含：核心心智模型、决策启发式、表达 DNA、价值观、小说化特征等。

用于：剧情推演中让 AI 以角色的思维方式做决策；章节撰写中让 AI 写出符合角色性格的对话和行动。

## 6 路并行 Probe

| Probe | 研究内容 | 用于 SKILL.md 的哪部分 |
|-------|---------|---------------------|
| writings | 著作/原著行为与系统思考 | 核心心智模型、决策启发式 |
| conversations | 对话/台词风格与即兴反应 | 台词指纹、情感表达 |
| expression_dna | 句法、修辞、情感峰值 | 表达 DNA、语言肌肉记忆 |
| external_views | 他人评价/读者看法 | 价值观、反模式、诚实边界 |
| decisions | 重大决策与选择模式 | 决策启发式、成长潜能 |
| timeline | 成长弧光与智识谱系 | 人物时间线、成长潜能 |

## 三阶段工作流

### 阶段 1：生成研究 Prompts

```bash
ws distill-soul "孙悟空" --source "《西游记》" --type fictional
```

生成 `souls/孙悟空/research/{probe}_prompt.md`。

### 阶段 2：并行填充研究内容

启动 6 个 Claude Agent 并行填充 research 文件。每个 Agent：
- 使用 WebSearch 搜索资料
- 优先一手来源（原著/访谈原文）
- 每条事实标注 `[一手]` / `[二手]` / `[推断]`
- 输出不少于 800 字的中文结构化报告

### 阶段 3：合成 SKILL.md

```bash
ws distill-soul "孙悟空" --synthesize
```

读取 6 个 probe 结果，综合提炼生成 `souls/孙悟空/SKILL.md`。

### 阶段 4：验证

```bash
ws distill-soul "孙悟空" --validate
```

三重验证评分（cross_domain / generative / exclusivity），overall >= 7 为通过。未通过时自动注入修复建议并重试一次。

## 小说化特征（灵魂蒸馏特有）

标准 6 probe 之外，SKILL.md 还包含：

- **台词指纹**：口头禅、句式长度、语气词
- **行动模式**：面对冲突的首选策略（战斗/逃跑/谈判/欺骗/隐忍）
- **情感表达**：喜怒哀乐外放还是压抑、爆发点
- **人际化学反应**：对权威/弱者/对手/盟友/恋人的互动模式
- **冲突风格**：怎么打架、怎么吵架、怎么博弈
- **成长潜能**：在长篇中的弧光与瓶颈

## 信源标记规范

- `[一手]` = 本人著述/演讲/采访原文 或 原著直接描写
- `[二手]` = 他人转述/评论/改编解读
- `[推断]` = 基于一手二手的合理推断

## 注意事项

- 虚构角色的 `--source` 建议填写作品名（如 `《西游记》`），方便 Agent 搜索
- 真人的 `--type real` 会从公开著作、访谈、媒体报道中蒸馏
- 验证未通过时，修复建议会自动注入 SKILL.md 末尾
- 所有 probe 结果保存在 `research/` 目录，是 SKILL.md 的素材来源
