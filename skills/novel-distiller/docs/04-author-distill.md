# 作者蒸馏（Author Distillation）

## 概念

作者蒸馏是从作家的公开作品、访谈、创作谈中提炼**写作 DNA**——不是模仿文风，而是提取可操作的创作规则：叙事结构癖好、语言肌肉记忆、母题与执念、信息密度策略、创作决策模式。

用于：章节撰写时作为风格基线注入，确保 AI 写作不会中途"变味"。

## 与灵魂蒸馏的区别

| | 灵魂蒸馏 | 作者蒸馏 |
|---|---|---|
| 对象 | 角色（真人或虚构） | 作家（真人） |
| 产物用途 | 角色扮演/推演决策 | 风格基线/章节撰写 |
| probe 侧重 | 行为模式、决策、成长 | 写作签名、结构、语言 |
| 标记 | `perspective` | `author-perspective` |

## 6 路并行 Probe

| Probe | 研究内容 | 用于 SKILL.md 的哪部分 |
|-------|---------|---------------------|
| writings | 写作签名（母题、结构、密度） | 叙事结构癖好、母题与执念 |
| conversations | 访谈口吻（口语 vs 书面差异） | 对话写法特色、创作理念 |
| expression_dna | 表达指纹（句法、修辞、情感峰值） | 语言肌肉记忆、表达 DNA |
| external_views | 批评界评价 | 批评界评价摘要、风格边界 |
| decisions | 创作决策（题材选择、商业化路径） | 创作决策模式 |
| timeline | 创作生涯进化 | 创作生涯时间线 |

## 写作时的注入方式

`write.py` 在生成 `ch{NNN}_prompt.md` 时，自动将作者 SKILL.md 的前 3000 字注入到写作指令的「作者风格基线」部分。写作 Agent 必须严格遵守。

## 注意事项

- 建议为每个作品指定 1-2 个参考作者，避免风格混杂
- 如果作品中需要多种风格（如不同角色的 POV 章节），可以为不同角色指定不同作者
- 作者 SKILL.md 不影响角色 SKILL.md，两者在写作时分别注入不同部分
