# 创世蓝图（Genesis Blueprint）

## 概念

创世蓝图是 WS 方法论的第一步：从一个模糊的想法，生成结构化的小说项目骨架。它不是写小说，而是**设计小说**——确定类型、篇幅、平台、核心角色、世界观框架、章节大纲和暗线配置。

## 工作流程

```
用户想法
    ↓
[CLI] ws init
    ↓
作品骨架（7 个文件）
    ↓
用户编辑完善
```

## 生成的文件

| 文件 | 作用 | 是否必填 |
|------|------|---------|
| `work_intro.md` | 作品简介、卖点、对标作品 | 是 |
| `worldviews/` | 世界观设定目录 | 需后续填充 |
| `chapters/outline.md` | 章节大纲表格 | 需后续填充 |
| `dark-threads/config.yaml` | 暗线配置 | 自动生成，可调整 |
| `dark-threads/config_prompt.md` | 暗线优化提示 | 自动生成 |
| `author_soul.md` | 作者灵魂方案 | 自动生成 |
| `protagonist.md` | 主角初始设定 | 自动生成 |

## 参数说明

```bash
ws init "作品想法" \
  --genre "玄幻" \          # 类型：玄幻/科幻/都市/悬疑/历史/言情/...
  --length short \         # 篇幅：short(短篇 8K-3万字) / medium(中篇 3-10万字) / long(长篇 10万+)
  --platform tomato \      # 平台：generic / tomato / qidian / zhihu
  --gender male \          # 受众：male(男频) / female(女频) / unsure
  --style-author "刘慈欣" \ # 参考作者风格（可选）
  --core-chars 3           # 核心角色数量（默认3）
```

## 暗线配置自动生成

`scaffold.py` 内置了 10 种类型模板：

| 类型 | 数值变量示例 | 暗线示例 |
|------|-------------|---------|
| 玄幻/仙侠/武侠 | 境界、气运值、功法进度、仇敌值 | 宿命觉醒、宗门态度、神器封印 |
| 科幻 | 科技等级、势力声望、资源点、文明指数 | 人工智能叛变、外星文明接触、技术奇点 |
| 都市 | 财富值、人脉网、势力影响力、健康状况 | 幕后黑手身份、商业联盟、情感羁绊 |
| 悬疑/推理 | 线索碎片数、嫌疑人信任度、真相进度 | 真凶动机、证人保护、警局内鬼 |
| 历史/军事 | 势力版图、兵力、粮草、民心 | 权臣野心、敌国间谍、太子之争 |
| 言情 | 情感进度、误会指数、外部压力值 | 家族恩怨、身份秘密、第三者介入 |

篇幅影响暗线数量：
- 短篇：1-2 条暗线
- 中篇：2-4 条暗线
- 长篇：3-6 条暗线

## 下一步

1. 编辑 `work_intro.md` 完善卖点和对标作品
2. 编辑 `worldviews/*.md` 填充世界观
3. 编辑 `chapters/outline.md` 完善章节大纲
4. 检查 `dark-threads/config.yaml` 确认暗线配置
5. 运行 `ws distill-soul` 开始角色蒸馏
