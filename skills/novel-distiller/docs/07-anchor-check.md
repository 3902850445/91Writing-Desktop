# 锚定自检（Narrative Anchor / Consistency Engine）

## 概念

锚定自检解决 AI 写长篇小说时的核心漂移问题：
- 人物性格跳脱（OOC）
- 暗线到下个场景就忘
- 世界观数值前后矛盾
- 情节逻辑不自洽
- 风格中途变味
- 平台审核踩雷

它不是"我觉得写得不错"，而是**用规则和标准打分**。

## 8 维评分

每项 0-10 分，加权计算总分：

| 维度 | 权重 | 评分要点 |
|------|------|---------|
| 世界观合规 | 12% | 内部规则不自相矛盾，数值一致 |
| 结构完整 | 12% | 开头有钩子，中间有递进，结尾有悬念 |
| 角色刻画 | 12% | 行为符合 SKILL.md，无 OOC |
| 情节逻辑 | 12% | 因果通顺，无硬伤 |
| 爽点情感 | 12% | 情绪节奏合理，有释放点 |
| 语言风格 | 12% | 符合作者风格 DNA |
| 推演输入完整 | 14% | 使用了场景推演报告的内容 |
| 推演-正文一致 | 14% | 正文与推演报告无偏离 |

**通过门槛**：总分 >= 8.0

## 必过项（任一失败则整章不通过）

- [ ] 世界观与章节划分合规
- [ ] 人物无 OOC
- [ ] 暗线无遗忘
- [ ] 版权安全

## 两阶段检查

### 阶段 1：基础检查（自动化）

```bash
ws check 1 --platform tomato
```

运行可自动化的规则检查：
- 字数检查（是否达标）
- 章末钩子检查（最后 150 字是否有悬念标点或关键词）
- 角色一致性检查（角色名是否出现）
- 世界观关键词检查（世界观术语是否在正文中出现）
- 暗线连续性检查（暗线关键词是否在正文中出现）
- 推演一致性检查（场景报告中的事件是否在正文中有体现）
- 平台规则检查（番茄/起点/知乎的叠加规则）

生成两个文件：
- `ch{NNN}.report.md` — 报告模板（含基础评分）
- `ch{NNN}_check_prompt.md` — 评估指令（供 Agent 使用）

### 阶段 2：深度评估（Claude Agent）

启动评估 Agent，读取 `ch{NNN}_check_prompt.md`（包含章节正文 + 所有参考素材），对 8 个维度分别打分，输出 JSON 格式：

```json
{
  "dimension_scores": {
    "世界观合规": 9.0,
    "结构完整": 8.5,
    ...
  },
  "must_pass": {
    "世界观与章节划分合规": true,
    "人物无 OOC": true,
    "暗线无遗忘": true,
    "版权安全": true
  },
  "overall": 8.75,
  "fix_suggestions": ["..."]
}
```

Agent 将 JSON 填入 `ch{NNN}.report.md` 的对应位置。

## 平台叠加规则

### 番茄小说（tomato）
- 正能量导向：主角整体形象积极向上
- 章末钩子：每章结尾必须有继续阅读动力
- 节奏明快：每 1000 字至少一个小爽点或信息增量
- 冲突清晰：每章至少一个明确的冲突或矛盾
- 红线扫描：无暴恐、无色情、无抄袭

### 起点中文网（qidian）
- 升级感：主角能力/地位有可见提升
- 打脸频率： antagonist 受到惩罚
- 期待感：下一章的预告或铺垫
- 章末钩子：悬念/危机/反转

### 知乎盐选（zhihu）
- 悬念密度：每 500 字至少一个信息增量
- 反转：章节中至少有 1 次意外转折
- 付费点：章节结尾处设置"必须付费才能看后续"的钩子

## 素材完整性检查

自检会检查以下素材是否存在：
- [ ] 章节正文 (`chapters/ch{NNN}.md`)
- [ ] 场景推演报告 (`scenes/{scene_id}/report.md`)
- [ ] 角色 SKILL.md (`souls/{slug}/SKILL.md`)
- [ ] 世界观设定 (`worldviews/*.md`)
- [ ] 暗线状态 (`dark-threads/ch*_snapshot.md`)
- [ ] 作者风格基线 (`souls/{author}/SKILL.md` 或 `author_soul.md`)

## 修复流程

1. 阅读 `ch{NNN}.report.md` 中的修复建议
2. 根据建议修改 `ch{NNN}.md`
3. 重新运行 `ws check {NNN} --platform {platform}`
4. 如果 `--rewrite` 标志存在且未通过，最多自动重写 3 次

## 注意事项

- 基础检查是自动化规则，分数偏保守（默认 5 分）
- 真正的评分由 Agent 深度评估完成
- 如果某个维度得分特别低，优先修复该维度的问题
- 必过项任一失败必须修复，否则章节不能进入下一流程
