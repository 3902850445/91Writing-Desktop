# 平台规则详解

## 概述

Novel Distiller 的锚定自检支持平台叠加规则。在基础检查（叙事连续性 + 人物一致性 + 暗线无遗忘）之上，根据目标平台叠加特定规则。

## 通用规则（generic）

所有平台共享的基础检查：

1. **叙事连续性**：时间/地点/关系不矛盾
2. **人物一致性**：角色行为符合 SKILL.md
3. **暗线连续性**：暗线推进合理，无遗忘
4. **情节逻辑**：因果通顺，无硬伤
5. **风格一致性**：符合作者灵魂方案 DNA
6. **版权安全**：不与参考原作一致，无侵权风险
7. **数值一致性**：功德/等级/物品数量前后一致

## 番茄小说（tomato）

### 必过红线
- 无暴恐描写（杀死、屠杀、碎尸、酷刑等）
- 无色情描写
- 无抄袭风险

### 节奏要求
- 正能量导向：主角整体形象积极向上，即便受挫最终也要向上
- 章末钩子：每章结尾必须有继续阅读动力（悬念/危机/反转/期待）
- 节奏明快：每 1000 字至少一个小爽点或信息增量
- 冲突清晰：每章至少一个明确的冲突或矛盾

### 审核避坑
- 避免政治敏感内容
- 避免宗教极端内容
- 避免现实中的负面社会事件映射
- 避免未成年人不良引导

## 起点中文网（qidian）

### 节奏要求
- 升级感：主角能力/地位有可见提升
- 打脸频率：antagonist 受到惩罚
- 期待感：下一章的预告或铺垫
- 章末钩子：悬念/危机/反转

### 爽点设计
- 金手指要明显且有效
- 反派要够坏且最终被打脸
- 每次升级都要有仪式感
- 地图切换要带来新期待

## 知乎盐选（zhihu）

### 节奏要求
- 悬念密度：每 500 字至少一个信息增量
- 反转：章节中至少有 1 次意外转折
- 付费点：章节结尾处设置"必须付费才能看后续"的钩子

### 叙事特点
- 第一人称或强 POV
- 信息差利用（读者知道但角色不知道，或反之）
- 结尾处情绪达到峰值后戛然而止

## 平台选择建议

| 你的作品特点 | 推荐平台 |
|-------------|---------|
| 日更 4000+，节奏明快，升级感强 | qidian |
| 短篇/中篇，悬念密集，反转多 | zhihu |
| 传统叙事，正能量导向，大众向 | tomato |
| 实验性写法，不追求爽感 | generic |

## 多平台适配

如果计划在多个平台发布，建议：
1. 先用 `generic` 规则写完初稿
2. 用 `qidian` 规则检查爽点密度，补充打脸和升级
3. 用 `tomato` 规则检查合规性，弱化暴力描写
4. 用 `zhihu` 规则检查悬念密度，强化反转和钩子

## 自定义平台规则

在 `novel_distiller/platform.py` 中添加新的平台规则，然后重新安装即可使用：

```python
PLATFORM_RULES = {
    "your-platform": {
        "platform_name": "你的平台",
        "must_have": ["规则1", "规则2"],
        "must_not_have": ["红线1", "红线2"],
    }
}
```
