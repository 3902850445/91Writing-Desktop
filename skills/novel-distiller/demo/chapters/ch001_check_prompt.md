# 第 1 章 火焰山

孙悟空把金箍棒往肩上一扛，咧嘴笑道：「牛大哥，五百年不见，你还是这般急性子。当年结拜的情分，你就真的一点不念？」

话说那火焰山火势凶猛，方圆百里寸草不生。唐僧师徒西行至此处，但见那山火红一片，热浪滚滚，连那白龙马都焦躁不安，连连嘶鸣。

「师父莫慌，有俺老孙在！」孙悟空安抚了唐僧，一个筋斗云便来到火焰山前。只见那山脚下岩浆翻滚，热气蒸腾，寻常人莫说靠近，便是站在十里之外也要被烤得口干舌燥。

正思索间，忽见一道黑影从天而降，落在岩浆河畔。那人身高丈二，头生双角，手持一把巨大的芭蕉扇，正是牛魔王。

「少来这套！」牛魔王冷哼一声，芭蕉扇横在胸前，「你保唐僧西天取经，与我何干？想借扇，先问问俺这扇子答不答应！」

说罢猛地一扇，狂风卷起岩浆河的热浪直扑孙悟空。那猴子被热浪逼退三步，但火眼金睛已看清芭蕉扇的握柄处有一道旧裂痕——那是五百年前大闹天宫时留下的痕迹。

孙悟空心中暗喜，却不动声色，反而假装被热浪逼得手忙脚乱，连连后退，口中喊道：「牛大哥好手段！俺老孙认输，认输！」

他故意将金箍棒收短，做出防御姿态，实则暗中蓄力，目光始终锁定芭蕉扇柄上的裂痕。

牛魔王眼中闪过一丝得意，大步逼近：「现在知道怕了？晚了！」

他高举芭蕉扇，准备全力一扇。就在扇子挥到最高点的瞬间——

孙悟空突然暴起！金箍棒如闪电般直击芭蕉扇柄上的裂痕。只听「咔嚓」一声，扇柄裂纹扩大，芭蕉扇的光芒顿时黯淡了几分。

牛魔王又惊又怒：「你——你怎么知道——」

芭蕉扇受损后，扇出的狂风方向开始失控，一部分热风反而卷向牛魔王自己。更意外的是，岩浆河被这股失控的狂风吹得泛起巨浪，一块暗礁浮出水面——那上面竟刻着古老的封印符文，似乎与孙悟空的出身有关。

二人对视一眼，两个五百年的宿敌，竟因为这意外的发现而达成了暂时的同盟……
