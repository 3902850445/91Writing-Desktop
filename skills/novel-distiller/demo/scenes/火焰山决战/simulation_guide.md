# 剧情推演操作指南

## 场景
场景: 火焰山决战

## 参与角色
- **孙悟空**: 加载 souls/孙悟空/SKILL.md 作为思维操作系统
- **牛魔王**: 加载 souls/牛魔王/SKILL.md 作为思维操作系统

## 推演协议

### 1. 加载角色灵魂
每个角色 Agent 必须以其 SKILL.md 作为系统提示，严格保持角色性格一致性。

### 2. 串行执行规则
- 每轮按固定顺序让角色依次行动
- 后动者能看到先动者的 Thought + Action
- 不允许角色预知未来或读取其他角色的内心（除非有读心设定）

### 3. ReACT 格式
每个角色的每轮输出必须包含：
```
### Thought: [角色名]
...

### Action: [角色名]
...
```

### 4. Observation 规则
所有角色行动完毕后，生成 Observation：
- 环境对行动的反馈
- 未预料到的连锁反应
- 场景状态变化（地形/天气/物品/角色状态）

### 5. 意外发现记录
如果推演过程中出现令人意外的剧情走向（角色做出出乎意料的选择、产生新的冲突、揭示隐藏信息），请单独记录在 surprises 列表中。

## 轮次设置
总轮数: 3
推荐轮数: 短篇=3 中篇=5 长篇=7

## 输出要求
- 每轮结果保存到 scenes/火焰山决战/rounds/round_NN.md
- 所有轮次完成后，运行 `ws plot "火焰山决战" --report` 生成报告
