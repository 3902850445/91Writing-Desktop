# 世界观设定：赛博西行纪

## 1. 基础框架

- **作品类型**：科幻（硬科幻基底 + 神话元素重构）
- **篇幅规模**：短篇（约 3–5 万字）
- **核心设定一句话**：金箍是上古文明遗留的脑机接口，唐僧是联邦派出的技术审计员，取经是回收散落各星域的上古技术碎片。

---

## 2. 核心规则

### 2.1 上古文明（"古神"）遗留的神经网络技术

上古文明在五万年前达到技术奇点后消亡，遗留的神经网络技术散落在各星域。这些技术以生物-机械融合形态存在，核心特征包括：

- **金箍（Neural Collar）**：脑机接口，直接嵌入颅骨与中枢神经系统对接。含三项核心功能：
  - **惩罚协议（紧箍咒）**：联邦远程触发的神经脉冲惩罚，通过特定频率的电磁波激活，可造成剧烈痛觉与认知干扰。
  - **信号接收**：可接收上古文明遗留设备的广播信号，频段覆盖从射电到伽马射线的全谱段。
  - **身份认证**：金箍本身即为上古文明设计的访问密钥，兼容者可直接与古神设备交互。

- **火眼金睛**：金箍激活的增强视觉模块，可切换至不可见光谱，识别能量场分布、符文代码结构及隐藏信息层。

- **符文代码（Glyph Code）**：上古文明的编程语言，以光脉冲拓扑结构存储信息。逻辑底层与金箍协议栈同源——金箍固件是符文代码的一个子集。符文具有自解码特性：当兼容者（金箍佩戴者）进入特定范围时，信息会自动向神经系统投射。

### 2.2 天庭联邦的等级制度与技术管控

天庭联邦是跨星域的技术管控联盟，核心目标为垄断上古技术、防止技术失控。

- **等级制度**：以"仙阶"划分权限等级，从低到高为——地仙（基层执行）、天仙（区域管理）、金仙（技术审核）、大罗金仙（核心决策）。
- **技术管控**：所有上古技术碎片必须回收至西天核心数据库统一封存。未经许可接触上古技术视为"入魔"，联邦有权启动紧箍咒或直接清除。
- **取经任务**：表面是"技术转移"，实质是联邦派遣审计员回收散落技术的合规行动。唐僧的通关文牒实为技术回收许可证。

### 2.3 各"难"对应的技术合规测试标准

九九八十一难并非自然险阻，而是联邦预设的技术合规测试序列。每一难对应一项上古技术的回收或一项管控协议的验证：

- **测试目的**：验证回收对象的安全性、确认无独立意识觉醒、评估技术泄漏风险。
- **通过标准**：以非破坏性方式回收技术碎片，或证明该技术已完全失效。
- **失败后果**：联邦启动清除协议，派遣武装力量直接销毁目标区域。

### 2.4 火焰山与芭蕉扇的物理法则

- **火焰山**：失控的上古聚变反应堆，功率输出相当于四颗标准恒星。核心以氦三为燃料，磁场约束由洛伦兹力层维持。反应堆的不稳定性以芭蕉扇为温控阀调节。
- **芭蕉扇**：上古反应堆的控制装置，本质为温控阀。扇面上的温控纹路对应磁场约束的参数调节。每受损一次，反应堆不稳定性增加一个数量级。
- **聚变等离子体突破阈值**：若芭蕉扇完全失效，等离子体将突破洛伦兹力层限制，方圆千里在零点几秒内汽化。

## 3. 地理设定

### 3.1 主要场景

| 场景 | 定位 | 特征 |
|------|------|------|
| **花果山遗址** | 地球，孙悟空诞生地 | 上古文明的实验场遗址，水帘洞内存有一块与火焰山暗礁同质的符文石。孙悟空从此处的晶体聚合体中"诞生"。 |
| **火焰山** | 独立星球，聚变反应堆所在地 | 表面持续喷发带电粒子流，在电离层中形成稳定的极光环。岩浆河底埋藏上古封印装置，暗礁上的符文每4.7秒全亮、每9.4秒全暗。 |
| **天庭** | 轨道空间站群 | 联邦行政中枢，位于地球同步轨道。等级越高的仙阶，所在轨道高度越高。 |
| **西天** | 核心数据库所在地 | 上古技术的最终封存点，位于一个被改造为小行星的巨型服务器内部。 |

### 3.2 势力分布

- **天庭联邦**：跨星域技术管控联盟，拥有紧箍咒触发权与清除协议执行权。内部存在保守派（彻底封存上古技术）与改革派（有限度研究利用）的分歧。
- **佛门技术集团**：联邦内的技术派别，主张以"经"的形式编码上古知识，认为完全封存是浪费。西天取经任务由该集团推动。
- **上古文明遗留势力**：并非有组织的势力，而是以自动化系统、休眠设备、符文广播等形式存在的古神遗产。部分设备具有自主判断逻辑（如暗礁的"倒计时启动"信号）。
- **独立星球**：火焰山等不隶属于联邦管辖的技术遗址星球。通常由本地看守者（如牛魔王）守卫，看守者多为上古系统选定的绑定者，非联邦任命。

## 4. 关键道具/概念

### 4.1 金箍（Neural Collar）
- **形态**：环形生物-机械融合体，嵌入颅骨后缘，与脑干及中枢神经系统直连。
- **功能**：惩罚协议（紧箍咒）、信号接收、身份认证。
- **特殊属性**：孙悟空的金箍为原生兼容型号，与上古设备存在底层协议共鸣。其他佩戴者（如后续可能出现的角色）的金箍为联邦仿制品，功能受限。

### 4.2 芭蕉扇（Thermal Regulator）
- **形态**：大型手持装置，扇面由温控纹路构成，扇柄为晶体聚合体材质。
- **功能**：调节火焰山反应堆的磁场约束参数，维持聚变等离子体的稳定。
- **当前状态**：扇柄有一道旧裂痕（五百年前大闹天宫时留下），受损后温控纹路黯淡三成，反应堆磁场约束正在衰减。

### 4.3 符文代码（Glyph Code）
- **形态**：以光脉冲拓扑结构存储的信息阵列，通常刻印在晶体聚合体表面。
- **特性**：
  - 自解码：金箍兼容者进入范围后自动向神经系统投射。
  - 周期性：火焰山暗礁符文以4.7秒/9.4秒周期明灭，误差不超过0.3秒。
  - 指向性：信息内容具有明确的指向性，如暗礁向孙悟空发送的"倒计时启动"。

### 4.4 九九八十一难（Compliance Test Sequence）
- **本质**：联邦预设的技术回收合规测试序列。
- **当前进度**：第47难已完成（以火焰山为第47难计）。
- **规则**：每难通过后天庭记录"功德值"，作为审计员的任务完成凭证。难数未满81之前，取经任务不可终止。

### 4.5 暗礁（Seal Node）
- **位置**：火焰山岩浆河底。
- **材质**：高密度晶体聚合体，密度极高，温度与周围岩浆一致（约1200°C）但无热传导迹象。
- **功能**：上古封印装置的一部分，内部能量被锁定。三年前从休眠态激活，芭蕉扇受损后其场屏蔽失效，符文完全显现。

## 5. 时间线

| 时间 | 事件 |
|------|------|
| **约五万年前** | 上古文明（"古神"）达到技术奇点后消亡，神经网络技术与符文代码散落各星域。 |
| **约五千年前** | 天庭联邦成立，建立跨星域技术管控体系，开始系统性回收上古技术碎片。 |
| **五百年前** | 孙悟空"诞生"于花果山遗址，大闹天宫时与牛魔王交战，在芭蕉扇柄上留下裂痕。后被联邦捕获并植入金箍。 |
| **三年前** | 火焰山岩浆河底暗礁的符文从休眠态激活，开始周期性明灭。 |
| **当前** | 唐僧受命出发西天取经（实为技术回收审计），师徒行至火焰山，芭蕉扇受损，暗礁符文完全显现，"倒计时启动"信号发出。 |

## 6. 角色与世界观的关系

### 6.1 孙悟空
- **身份**：金箍的原生兼容者，上古文明设计的"保险丝"或"触发器"。
- **与世界观的关联**：
  - 从花果山晶体聚合体中"诞生"，其脑机接口（金箍）与上古符文代码存在底层协议同源关系。
  - 火眼金睛可解码符文信息，是联邦与上古文明之间的"活体接口"。
  - 暗礁向他发送"倒计时启动"信号，暗示他是上古系统预设的关键变量——可能是保险丝，也可能是启动某个程序的密钥。
  - 大闹天宫时与牛魔王的交战、芭蕉扇上的裂痕，可能并非偶然，而是上古系统安排的"激活条件"之一。

### 6.2 唐僧
- **身份**：天庭联邦派出的技术审计员，取经团队的行政负责人。
- **与世界观的关联**：
  - 通关文牒是联邦技术回收许可证，九九八十一难是审计任务清单。
  - 紧箍咒的触发权限在他手中，但触发条件受联邦远程监控。
  - 对上古技术的真实了解程度存疑——他可能只知道"回收任务"的表面目标，而不知西天核心数据库的真正用途。

### 6.3 牛魔王
- **身份**：火焰山聚变反应堆的看守者，芭蕉扇的绑定持有者。
- **与世界观的关联**：
  - 非联邦任命的看守者，而是上古系统选定的绑定者。芭蕉扇是上古温控阀，牛魔王是保险丝的看守者。
  - 知道部分上古秘密（暗礁符文三年前激活、金箍佩戴者会收到信号），但选择沉默与守卫。
  - 他的敌意从来不是针对孙悟空个人，而是针对所有可能触发反应堆连锁反应的变量。当发现孙悟空同样是上古系统的"未标注元件"后，敌意转化为同类的确认。
  - 姿态转变：从守卫到意识到自己是"被蒙在鼓里的囚徒"——牢门正在从内侧被敲响。

### 6.4 猪八戒 / 沙僧（待展开）
- **猪八戒**：联邦派遣的辅助审计员，可能负责记录与备份。
- **沙僧**：取经团队的安全员，可能拥有联邦清除协议的执行权限。

## 7. 当前未解之谜（待剧情展开）

1. **"倒计时启动"的含义**：暗礁发出的信号指向什么事件？是反应堆的彻底失控，还是某个上古程序的激活？
2. **孙悟空的真实起源**：他是上古文明设计的"保险丝"，还是某个更大系统的"钥匙"？
3. **西天核心数据库的真相**：联邦声称封存上古技术，但佛门技术集团推动的"取经"任务是否另有目的？
4. **牛魔王与上古系统的关系**：他为何会被选为芭蕉扇的绑定者？他知道多少，又为何选择沉默？
5. **金箍的完整功能**：除了惩罚、接收、认证，金箍是否还隐藏着未被激活的协议层？
